Tcl/Tk 8.6.18 Releases

Guide to downloadable files:

tcltk-release-notes-8.6.18.txt:
	Detailed notes on changes and incompatibilities in the Tcl and Tk
	8.6.18 releases compared with prior releases.  Links to online
	resources.

tcl8.6.18-html.tar.gz
	Documentation for all packages available for download rendered
	in HTML files, packaged as a gzipped tar archive file.

tk8618-src.zip
	Same contents as tk8.6.18-src.tar.gz, packaged as a zip archive.

tk8.6.18-src.tar.gz
	The source code distribution of Tk 8.6.18, packaged as a gzipped
	tar archive file.

tcl8618-src.zip
	Same contents as tcl8.6.18-src.tar.gz, packaged as a zip archive.

tcl8.6.18-src.tar.gz
	The source code distribution of Tcl 8.6.18, packaged as a gzipped
	tar archive file.  This archive is made up of the combined
	contents of all the archives below.

tcl-core8.6.18-src.tar.gz
	The source code distribution of Tcl 8.6.18 alone, stripped of all
	the bundled packages in the pkgs subdirectory, packaged as a
	gzipped tar archive file.

itcl4.3.7.tar.gz
	The source code distribution of Itcl 4.3.7 (aka [incr Tcl]),
	packaged as a gzipped tar archive file.

thread2.8.13.tar.gz
	The source code distribution of Thread 2.8.13, packaged as a
	gzipped tar archive file.

sqlite3.53.0.tar.gz
	The source code distribution of sqlite3 3.53.0 (Tcl interface
	to SQLite 3), packaged as a gzipped tar archive file.

tdbc1.1.13.tar.gz
	The source code distribution of tdbc 1.1.13 (Tcl DataBase
	Connectivity), packaged as a gzipped tar archive file.

tdbcmysql1.1.13.tar.gz
	The source code distribution of tdbc::mysql 1.1.13 (TDBC
	Driver for MySQL), packaged as a gzipped tar archive file.

tdbcodbc1.1.13.tar.gz
	The source code distribution of tdbc::odbc 1.1.13 (TDBC
	Driver for ODBC), packaged as a gzipped tar archive file.

tdbcpostgres1.1.13.tar.gz
	The source code distribution of tdbc::postgres 1.1.13 (TDBC
	Driver for PostgreSQL), packaged as a gzipped tar archive file.

tdbcsqlite3-1.1.13.tar.gz
	The source code distribution of tdbc::sqlite3 1.1.13 (TDBC
	Driver for SQLite 3), packaged as a gzipped tar archive file.
