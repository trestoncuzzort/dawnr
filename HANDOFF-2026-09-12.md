## What t is, in one paragraph

t is a small specification language. A task is a `.t` file under
t/tasks: params, requires, ensures, a body with loops and invariants. Seven
lowerings turn a task into Dafny, Verus, SPARK, Frama-C, Lean, Rocq and F*
source; seven verifiers run the kernels and read verdicts. Every task is
graded twice: the real (must be VERIFIED) and a twin, a mutated program the
harness picks by a fixed ladder and grounds with a witness (a concrete input
where the twin's output differs); the twin must be REFUTED, and a kernel
refutes it by accepting a certificate the lowering emits from that witness.
A row "counts" only when all seven columns read verified / refuted.

## How work is done here (the recipe that held all night)

- Builders in git worktrees, one item each, with an independent
  adversarial checker per item; every claim measured at flake 3, every
  emitted file grepped for assume/admit/sorry/Admitted/axiom/trusted; no
  budget constant raised; a timeout closes only by a proof inside the
  pinned budget; the ensures and requires the kernel checks are the task's
  own. Model for builders: sonnet (fable burns the weekly limit too fast,
  Treston's call at 08:00Z).
- Merge: `git apply --3way` each patch, em-dash scan (a grep for U+2014, none
  allowed in repo prose), py_compile, wire new test files into
  t/reproduce.sh's run_tests list, run the quick tests, then the gate in
  tmux: ~/tup/tup-reports/vram/wave-gate.sh <name> (conformance, the 34-task
  matrix diffed against the bank, `reproduce.sh --tests`). For a one-kernel
  change, that kernel's conformance column and the sweep rows it had
  verified/refuted are the bar (wave J's dafny trigger regressed two lifted
  rows the matrix did not cover).
- Commit explicit paths (never `git add -A`), `git fetch origin main &&
  git merge --ff-only origin/main` first, push after every workflow, no
  attribution lines. Heavy jobs in tmux, logs under ~/.local/share/tjob.
  Never pgrep/pkill/ps|grep (use ~/.claude/bin/tjob). Never sudo, never
  pip outside a venv, never touch Erfan's processes, never start ollama.
- Sweep: ~/tup/tup-reports/vram/sweep-r23.sh's pattern (bump r23 to r24):
