## The goal

locallm builds AI models from scratch, on any hardware, from any data. t is the filter: seven independent checkers must prove a program keeps its promise and catch a deliberately broken copy of it. locallm builds only from what passes, so the models it builds write clean output. The aim is small models that compete on reliability per parameter, backed by a check anyone can rerun.

## Where things stand

- Coverage: 57 of the 164 MBPP-DFY programs and 192 of 326 lifted tasks read verified in all seven checkers (sweep r27); the matrix reads 30 of 34.
- First filter-loop result (`t/runs/2026-09-16/`): at the same data size, a model built from clean tasks wrote 46 clean programs of 500, one built from raw 27B output wrote 3; the clean loop reached 57 at round 1.
- Held out: the model built from the clean corpus solved 0 of 232 held-out problems. It recites verified tasks it memorized (151 exact copies). A filter needs the checkers, the problem's tests and a copy check together, and the pool needs many more problem examples.
- The 27B wrote 3 answer sets on the 649-problem pool; the clean pool from them is 47 train problems (`t/runs/2026-09-16/loop-data/`).
