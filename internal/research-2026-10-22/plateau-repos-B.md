# Plateau repository scout, batch B: infrastructure for breaking a supervised plateau

- Date (UTC): 2026-10-22 10:16 UTC
- Target: a 4B-parameter student fine-tuned with QLoRA that writes a Python solution, a formal specification in a small language we own, and a proof checked by seven verifiers. It ends fully clean on about 6 of 95 development problems, and supervised rows have not moved that count. The table lists open repositories that ship infrastructure which could run on one 8 GB laptop GPU and one 16 GB desktop GPU to break that plateau.
- Method (query counts): `gh search repos`, 231 query specifications, each run once and spaced 2 seconds apart: 180 exact-name queries (171 with --owner set to the expected owner, 9 without an owner), 26 free-text queries and 25 GitHub topic queries, sorted by stars, up to 30 results each. 228 specifications returned output: 187 with at least one repository and 41 with none. 34 failed on the first pass, most with HTTP 403 rate-limit errors; they were retried after a 20-second pause, up to two attempts each, and 31 recovered. Three still failed (exact-name queries for DafnyBench, SynCode and LoRA+). The output named 930 distinct repositories; candidates were chosen from those results and from prior knowledge of the field.
- Verification: each candidate name was checked with `gh api repos/OWNER/NAME` (293 calls). 270 returned repository JSON, covering 266 distinct repositories (four names resolved to a repository already present). 23 names did not resolve and were dropped. Of the 266, 16 were held back as weaker fits or duplicates, leaving the 250 rows below. Links are the `html_url` the API returned, so GitHub renames are followed (for example volcengine/verl is now verl-project/verl). Nothing was cloned.
- Licence: the SPDX id from the API. A licence that GitHub names "Other" (non-SPDX) is shown as other; a repository with no licence detected is shown as unknown. Permissive counts are therefore a floor. Stars and archive flags are as of the date above and move.
- Descriptions: what each repository ships comes from its GitHub description, its name and, where noted, its README. Memory figures appear only where a README states one; where none is stated, the row says so or says nothing. The "why it may help" column is the scout's judgement for this pipeline, not a measured result. Rows marked weak fit are included to reach the count and should be read as low priority.
- Tag key:
  - I1 RL or expert iteration with a verifier reward on small GPUs
  - I2 rejection-sampling loops (keep verified outputs and retrain)
  - I3 constrained or grammar-guided decoding
  - I4 test-time search with a verifier
  - I5 distillation from a local teacher
  - I6 memory-efficient fine-tuning
  - I7 data selection and dedup
  - I8 evaluation with seeds and paired tests
- Totals: 250 repositories, one row each. Tags, counted over the table (a row with two tags counts once under each): I1 60, I2 15, I3 25, I4 37, I5 18, I6 50, I7 24, I8 58.
- Permissive-licence repositories: 209 of 250 (Apache-2.0 127, MIT 76, BSD-3-Clause 5, BSD-2-Clause 1). Copyleft: 7 (GPL-3.0 2, LGPL-3.0 3, LGPL-2.1 1, AGPL-3.0 1). Licence named Other by GitHub, so not classified: 18. No licence detected (unknown): 16. Archived upstream: 15.
- Verification (2026-10-22 10:16 UTC): every one of the 250 links returned repository JSON from `gh api` during the run; the link column is the `html_url` the API returned.

- Checked after the scout (2026-10-22 10:35 UTC): 250 numbered rows, no em or en dashes; a fixed sample of 25 links returned HTTP 200, 25 of 25; the licence and star cells of five rows (trl, unsloth, ms-swift, LMFlow, Liger-Kernel) match the GitHub API (ms-swift two stars apart, live drift).
